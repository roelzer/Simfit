## Liefert (exakt)
**`garmin/garmin_cloud.py`:**
- `DAY_PARTS: tuple[str, ...] = ("stats", "sleep", "hrv", "body")` (feste Reihenfolge).
- `class GarminCloudSource` mit `name = "garmin"`; `__init__(self, settings: Settings, *, open_client: Callable[[str], TokenClient] = open_token_client, sleep: Callable[[float], None] = time.sleep, rand: Callable[[], float] = random.random)`. **Der Konstruktor ruft Garmin nie** (wird auch von `/health` erzeugt).
- Client wird beim ersten `fetch_*` erzeugt (`load_tokens` → `open_client`), **genau ein Token-Login je Instanz** (= je Lauf); keine Tokens → `AppError("garmin_auth_required")`.
- Takt: vor jedem Garmin-Aufruf außer dem ersten der Instanz `sleep(pause_s + rand() * jitter_s)`; bei `garmin_call_pause_s == 0` keine Pause. Vor jedem Aufruf `cancel.raise_if_cancelled()`.
- `fetch_day(day, cancel) -> SourceRecord`: Teile in `DAY_PARTS`-Reihenfolge; `None` (404) → Teil `None`, **nicht** in `failed_parts`; `AppError("garmin_unavailable")` → Teil `None` und in `failed_parts`; `garmin_rate_limited`/`garmin_auth_required` → sofort weiterwerfen (kein weiterer Aufruf). `key = day.isoformat()`.
- `fetch_activities(start, end, cancel) -> list[SourceRecord]`: ein Aufruf `get_activities_by_date(start, end)`; je Eintrag `key = str(activityId)`; Einträge ohne ganzzahliges `activityId` überspringen (Anzahl protokollieren, keine Inhalte); jeder Fehler wird weitergeworfen.
- `normalize_day`/`normalize_activity` → P4-Funktionen.
- `save_session() -> None`: nur wenn ein Client geöffnet wurde: `save_tokens(settings, client.dumps())`.

**`garmin/sources.py`:**
- `choose_source(ctx) -> DataSource | None`: `source_mode == "demo"` → `DemoSource`; `"garmin"` → `GarminCloudSource`, wenn `tokens_readable`, sonst `None`; `"auto"`: `tokens_readable` → `GarminCloudSource`; sonst `token_file_exists` **oder** `ever_connected` **oder** `has_garmin_rows` → `None`; sonst `DemoSource`. Kein Garmin-Aufruf.
- `garmin_connected(ctx) -> bool` = `tokens_readable(ctx.settings)`.

**`garmin/startup.py`:**
- `INITIAL_DEMO_DAYS = 30`.
- `load_initial_demo(ctx) -> bool`: nur wenn `choose_source(ctx)` eine Demo-Quelle ist **und** `not has_any_days`, `not ever_connected`, `demo_loaded_at is None` → `execute_sync(ctx, demo, 30)`; bei Status `ok` `demo_loaded_at = clock()` committen, `True`; sonst `False`.
- `run_startup(ctx) -> None`: `abort_stale_runs`, dann `load_initial_demo`. Fehler werden protokolliert und nicht weitergereicht (die App startet trotzdem; Lauf steht mit Status im Verlauf).

**`main.py`, Lebenszyklus:** Migration (unverändert, unter der Sperre) → `run_startup(ctx)` → `AutoSyncScheduler(ctx).start()`; beim Beenden `scheduler.stop()`.
