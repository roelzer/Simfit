# Bauplan P2 – Oberflächen-Grundlage (M1)

**Ziel:** Tailwind 4, shadcn/ui, Tokens aus `design/tokens.json`, Schrift Geist, Hell/Dunkel, Grundgerüst (AppShell mit 3 Breiten) und die gemeinsamen Bausteine aus DESIGN 10.1 – **nur mit Eigenschaften (Props), ohne API-Aufrufe**. Formatierer `lib/format.ts` neu.
**Schwierigkeit:** mittel – viel Oberfläche, aber keine Fachlogik; knifflig sind nur Zeitzonen in `format.ts` und die Tastaturbedienung.
**Risiko-Auslöser:** nein – keine Daten von außen, keine Geheimnisse, keine Schnittstelle. Sicherheitsprüfer am Meilenstein.
**Abhängig von:** V0, Designer (DESIGN.md, tokens.json liegen vor). **Parallel mit:** P1a, P1b, P3. **Merge erst nach P1b** (vor dem Merge auf P1b neu aufsetzen und `npm run build` laufen lassen).

## Randfälle
`formatDuration(0)` → `"0:00 min"`; `formatDuration(3600)` → `"1 h 0 min"`; negative oder `NaN`-Werte → `"–"`; `formatDate` am 29.03./25.10. ohne Verschiebung; ungültige Zeitzone in `formatTime` → Rückfall `Europe/Berlin` (kein Absturz); langer Text im DemoBanner bei 390 px bricht um.

## Eskalation (BLOCKIERT melden)
Die Abhängigkeits-Schranke lehnt ein Paket ab; shadcn-CLI braucht eine andere Tailwind-/React-Version als im Projekt; `tabular-nums` greift bei Geist nicht (dann Geist Mono für Zahlen vorschlagen und melden, nicht still umstellen); ein Token aus `tokens.json` fehlt für eine Rolle, die ein Baustein braucht.

## Selbstprüfung-Schwerpunkte
Architekturtest `test_design_keine_festen_farben` ist ab `components/ui/` scharf (keine Hex-/`rgb(`-Farben außerhalb `globals.css` und `ui/`); kein Baustein importiert `lib/api` außer `import type`; keine `Date.now()`/`new Date()` ohne Argument in `format.ts`; Sichtprüfung nach DESIGN 10.3 Nr. 10 (Playwright 1440 und 390 px, hell und dunkel, Demo-Band, Toast über der Tab-Leiste, kein waagrechtes Scrollen bei 390 px) mit einer Vorschau-Seite unter `frontend/tests/` bzw. Storybook-freiem Testrender.
